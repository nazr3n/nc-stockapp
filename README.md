# NC Stock Manager

Stock check app for Nazren's Clinic, Miri. Runs in the phone browser.

- Klinify stays the system of record. This app never changes Klinify.
- All counts, photos and imported reports are stored only on the phone that uses the app (browser storage). No stock or patient data is kept in this repository.
- Hosted with GitHub Pages from the `main` branch.

TEST VERSION: not an official record.
